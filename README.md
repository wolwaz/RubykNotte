# RubykNotte

**Disclaimer, this app is vibe coded entirely, and I have no idea what I'm even doing**

A lightweight Markdown editor written in pure Ruby + Tk.

## Goals

- Fast startup
- Low memory usage
- Comfortable writing
- Pure Ruby
- Pure Tk
- No Electron
- Large document support

## Features

- Markdown highlighting
- Find/Replace
- Themes
- Header navigation
- Word statistics
- Line spacing
